# File Transfer — تطبيق إرسال واستقبال ملفات (PC ↔ Android)

تطبيق واحد بلغة بايثون (Kivy) يعمل على الكمبيوتر والهاتف، ويسمح بإرسال واستقبال
الملفات بين الجهازين عبر نفس شبكة الواي فاي (Wi-Fi)، بدون إنترنت أو سيرفر خارجي.

## فكرة العمل
كل جهاز يشغّل خادم HTTP محلي صغير على المنفذ 8000. لإرسال ملف من جهاز إلى آخر:
تكتب عنوان IP الخاص بالجهاز الآخر داخل التطبيق، وتختار الملف، فيتم رفعه مباشرة.
كما يمكنك فتح `http://IP:8000` من أي متصفح لرفع أو تنزيل الملفات يدوياً.

---

## 1) التشغيل على الكمبيوتر (PC)

```bash
pip install -r requirements.txt
python main.py
```

سيظهر لك عنوان IP الخاص بجهازك داخل نافذة التطبيق (مثال: `http://192.168.1.5:8000`).
اكتب هذا العنوان في تطبيق الهاتف لإرسال الملفات إليه.

> ملاحظة: تأكد أن الكمبيوتر والهاتف متصلان بنفس شبكة الواي فاي، وأن جدار الحماية
> (Firewall) يسمح بالاتصال على المنفذ 8000.

---

## 2) بناء تطبيق الأندرويد عبر GitHub Actions

هذا المشروع يحتوي بالفعل على ملف `.github/workflows/build-apk.yml` الذي يبني
ملف APK تلقائياً باستخدام Buildozer على خوادم GitHub (لا تحتاج أي إعداد على جهازك).

### الخطوات:
1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع محتويات هذا المجلد بالكامل إليه:
   ```bash
   git init
   git add .
   git commit -m "File transfer app"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. اذهب إلى تبويب **Actions** في صفحة المستودع على GitHub.
   سيبدأ البناء تلقائياً (أول مرة قد يستغرق 15-25 دقيقة لأنه يُحمّل Android
   SDK/NDK كاملة).
4. بعد اكتمال البناء بنجاح (علامة ✅)، افتح تفاصيل التشغيل (run) واذهب لأسفل
   إلى قسم **Artifacts**، ستجد ملف `filetransfer-apk` — حمّله وفك الضغط عنه
   للحصول على ملف `.apk`.
5. انقل ملف الـ APK إلى هاتفك (عبر كابل، بلوتوث، أو أي وسيلة) وثبّته
   (قد تحتاج للسماح بـ "تثبيت من مصادر غير معروفة" في إعدادات الأندرويد).

يمكنك أيضاً تشغيل البناء يدوياً في أي وقت من تبويب Actions باستخدام زر
**Run workflow** (بفضل `workflow_dispatch` في ملف الـ workflow).

---

## 3) الاستخدام

- افتح التطبيق على الهاتف وعلى الكمبيوتر.
- كل جهاز يعرض عنوان IP الخاص به وكود QR (على الهاتف يمكنك مسح QR الظاهر
  على شاشة الكمبيوتر إن أردت التأكد من العنوان بسهولة).
- لإرسال ملف من الهاتف إلى الكمبيوتر: اكتب IP الكمبيوتر في خانة "عنوان الجهاز
  الآخر" داخل تطبيق الهاتف، ثم اضغط "اختر ملفاً وأرسله".
- لإرسال ملف من الكمبيوتر إلى الهاتف: نفس الشيء، لكن بالعكس (تكتب IP الهاتف
  في تطبيق الكمبيوتر).
- الملفات المستلمة تُحفظ في مجلد `FileTransferReceived` داخل مجلد المستخدم
  (Home) على كل جهاز، وتظهر أيضاً داخل واجهة التطبيق.

## هيكل الملفات

```
├── main.py                     # واجهة التطبيق (Kivy) — تعمل على PC و Android
├── server.py                   # الخادم المحلي لاستقبال/عرض الملفات

├── buildozer.spec              # إعدادات بناء تطبيق الأندرويد
├── requirements.txt            # مكتبات بايثون المطلوبة على PC
└── .github/workflows/build-apk.yml   # بناء APK تلقائي عبر GitHub Actions
```
